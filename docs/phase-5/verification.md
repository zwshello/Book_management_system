## 修复记录与边界

首轮三个服务联调发现 DRF 在 409 异常构造时将嵌套库存结果的布尔值/数字字符串化，使 borrow-service 无法确认 OUT_OF_STOCK，保留 PENDING。图书服务改为直接输出已持久化的原类型操作 JSON，并加入断言后，完整 HTTP 联调通过。

借书、归还的网络结果不明保留待处理状态和原操作号；恢复入口需要由运维执行或后续调度，不会自行后台无限重试。普通本人只读 JWT 在 token 剩余有效期内可能继续读取；写操作实时核对用户服务。没有已知阻塞问题。阶段 6 statistics-service 已通过各服务受保护的汇总 API 获取数据，未跨库查询；前端借阅页面已在阶段 7 实现。阶段 9 用户暂缓 Redis，完整部署仍属后续阶段。本记录保留阶段 5 的测试历史。
